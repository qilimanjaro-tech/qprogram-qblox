This package now requires qprogram 0.3, and the `qblox-default-v1` check on DRAG pulses reads `IQDrag`'s `duration` and `num_sigmas` in place of the removed `sigma`. A loop that changes the gaussian's sigma, `duration / num_sigmas`, now runs host-side whether it sweeps either field directly or through an expression such as `2 * v`; before, only a bare variable at `sigma` did.
