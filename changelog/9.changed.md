This package now requires qprogram 1.0. The `qblox-default-v1` check on DRAG pulses reads the two fields that set the gaussian's sigma, which is `duration / num_sigmas`, so a loop that sweeps either one runs host-side, one qblox shot per iteration. A loop sweeping `duration` used to stay real-time. Sweeping `amplitude` or `drag_coefficient` still does.
